E-Umroh & Haji Management System

Integrated Pilgrimage Travel Management & Reservation Information System.

Digital Hajj & Umroh Service Platform

This platform is specifically designed to modernize the business processes of Hajj and Umroh travel agencies. The main focus of the system is to provide ease for prospective pilgrims in transparently selecting worship packages, while providing powerful management tools for travel admins to manage departure manifests, pilgrim documents, and financial verification in one integrated dashboard.

Key Features:

  • Dynamic Package Catalog: Detailed package information includes flight schedules, hotels (star rating), travel routes, and seat quota remaining in real-time.
  • Digital Pilgrim Form: Self-input of pilgrim identity data (Passport, NIK, Vaccination) for manifest accuracy.
  • Manual Payment Validation: Bank transfer proof upload process equipped with WhatsApp notification system for instant admin confirmation.
  • Document Tracking: Document processing status (Visa, Passport, Manifests) that can be monitored directly by pilgrims through personal dashboard.
  • Comprehensive Admin Dashboard: Package inventory management, daily financial reports, and export of pilgrim data for airline/hotel manifest needs.

Technology Architecture:

  • Backend: Laravel PHP Framework (Transactional data security & PDF file processing).
  • Database: MySQL (Optimization of relations between pilgrim, package, and transaction tables).
  • Frontend: Clean UI using Tailwind CSS for comfortable access even by elderly pilgrims.
  • Notification: WhatsApp Gateway & Email SMTP integration for order status updates.

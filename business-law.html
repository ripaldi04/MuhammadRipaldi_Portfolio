Platform Bisnis & Hukum (Digital Commerce & Event Management)

bisnisdanhukum.com is a multifunctional platform that integrates digital education services with event management. It serves as an e-book marketplace specializing in business and legal content, a registration hub for interactive live courses, and a reservation management system for professional offline events.

Key Features:

  • E-Book Store: Automated E-book sales and distribution system.
  • Live Course System: Scheduling and registration management for interactive online courses (Live).
  • Offline Event Management: Ticket reservation and information management system for professional offline events.
  • Integrated Payment Gateway: Automated payment system supporting various transaction methods (Bank Transfer, E-wallet, etc.).
  • Responsive Interface: Modern interface that makes it easy for users to transact whether through desktop or mobile.

Technologies Used:

  • Frontend: Developed using HTML, Tailwind CSS, and JavaScript, with a strong focus on creating seamless transactional UX.
  • Backend: Built with PHP and the Laravel framework to handle complex business logic.
  • Database: MySQL for managing E-book inventory data, course participants, and transaction history.
  • Authentication: User account system for managing purchase history and service access.
  • Payment Integration: Payment Gateway API for real-time payment verification.

What I Did:

  • Building a secure e-commerce infrastructure for digital product sales (E-books).
  • Integrating the Live Course registration system with the participant data management.
  • Designing the offline event management module from information publishing to the ticketing system.
  • Implementing the Payment Gateway workflow to ensure instant and secure checkout processes.
  • Developing the Admin Dashboard system to monitor sales reports, course participant status, and event registrants in a centralized manner.
  • Optimizing website performance and security to handle traffic during large event registration launches.

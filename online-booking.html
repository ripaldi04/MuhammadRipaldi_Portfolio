Ternyaman.com Property Marketplace

ternyaman.com is a property marketplace platform designed to simplify the process of searching for and renting properties. Built on a modern monolithic architecture, this platform integrates property listing management, an automated reservation system, and transaction data processing within one secure ecosystem

Key Features:

  • Advanced Property Search: Property search based on coordinates and dynamic filters (price, facilities, rental type).
  • Booking & Reservation System: Availability checking algorithm to prevent overbooking in real-time.
  • Integrated Payment Gateway: Automatic payment processing using API (such as Midtrans) with instant payment status notifications.
  • Owner & Tenant Dashboard: Specialized management panels for property owners (unit & financial management) and tenants (order management).
  • Automated Invoicing: Automatic PDF invoice generation system after successful transactions.

Technologies Used:

  • Backend: Laravel Framework (PHP) with solid MVC architecture.
  • Database: MySQL with Indexing optimization and Relational Mapping (Eloquent ORM).
  • Frontend: Blade Templating combined with Tailwind CSS or Bootstrap.
  • Authentication: Laravel Breeze/Jetstream for login system and access rights management (RBAC).
  • Payment API: Payment Gateway integration for secure banking transactions.

What I Did:

  • Designed relational database schema using MySQL to efficiently store user, property, and transaction data.
  • Built backend business logic using Laravel for booking processes and data validation.
  • Implemented multi-file image upload feature for property galleries with file size optimization.
  • Integrated payment gateway webhooks to automatically update order status without admin intervention.
  • Optimized database query performance to keep property search fast even with large data volumes.

Through the implementation of Laravel and MySQL technologies, Ternyaman.com is able to provide a scalable, secure, and easy-to-manage platform, providing real solutions for the digital property ecosystem in Indonesia.
